# @heliogrid/i18n — ONE Lingui catalog (EN/HI/MR) for Next.js AND bare RN

## What lives here / what must never live here
- .po catalogs (src/locales/*/messages.po — the translation source of truth), their
  COMPILED messages.ts (generated by `lingui compile`, committed, biome-excluded), and
  the setupI18n()/catalogs exports.
- Shared cross-platform copy modules in `src/copy/` — pure data, extractor-swept via
  leading `/*i18n*/` message descriptors, with NO React and no `@lingui/react` import
  (`src/copy/api-error.ts`'s header states the dual-instance ESM/CJS reason and is the
  canonical explanation). Where a closed set exists, the module is a `Record` over the
  contracts enum. Screen-specific copy stays in its screen.
- NEVER: app copy hard-coded elsewhere, per-app catalogs, agent/WhatsApp templates
  (tenant DATA — docs/10 §7 · .claude/rules/i18n.md), raw Intl currency (formatMoney when
  domain's money slice lands).

## Commands
pnpm --filter @heliogrid/i18n extract     # sweep web+mobile+ui for messages (CI-guarded)
pnpm --filter @heliogrid/i18n build       # compile catalogs + tsc (compile alone: `compile`)
pnpm --filter @heliogrid/i18n typecheck

## Dependency policy
docs/architecture.md §2 i18n. `packages/ui` stays string-free — copy arrives as props.

## THE CONVENTION (until the swc-plugin note below is resolved)
Both platforms use runtime `<Trans id="<English source text>" />` from '@lingui/react' —
the id IS the English string, so ids double as msgids and the extractor keeps ONE entry
per message. Do NOT mix macro `<Trans>` and explicit-id usage for the same string: the
extractor forks them into duplicate .po entries (hit 2026-07-26, cost translations).

## Landmines
- `@lingui/swc-plugin` (5.11.0 AND 6.6.0) fails against Next 15.5.21's swc_core
  ("failed to invoke plugin") — that's why web can't use macros yet. Revisit on Next or
  plugin bumps; migrating BOTH platforms to macros is then one mechanical sweep (ids
  already equal source text).
- Compiled messages.ts are generated — never hand-edit; excluded from Biome.
- Hermes needs the @formatjs Intl polyfills BEFORE any ICU call (apps/mobile/src/i18n.ts).

## Definition of done here
extract leaves the tree clean (CI guard) · all locales 0 missing or the gap is
deliberate (English fallback) · Hindi verified RENDERED on web + both simulators.
