# packages/i18n — one catalog, two platforms

## Where files go

```
src/copy/<area>.ts          copy BOTH platforms need — pure data, no React, no JSX
src/locales/<lang>/         messages.po (source of truth) + messages.ts (compiled, committed)
src/index.ts                REACT-FREE root — createI18nRuntime, createTranslator, metadata
src/languages.ts            LANGUAGE_META + the statically-imported source catalog
src/catalog-loader.ts       web: one import() chunk per language
src/catalog-loader.native.ts  RN: static imports (Metro substitutes it — see the landmine)
src/react/                  the ONE provider and hooks both platforms use
src/rn/                     Hermes Intl polyfills — global side effects, own entry
```

Screen-specific copy stays in its screen. `src/copy/` is for strings both platforms render.

## Rules

- ONE Lingui catalog serves web AND React Native. The language SET is `UI_LANGUAGES` in
  `packages/contracts/src/locale.ts` — never restate it. Registration is mechanical:
  `LANGUAGE_META` and both catalog loaders are `satisfies Record<UiLanguage, …>`, and the Hermes
  plural-rule import, which no type can see, is covered by `M48`.
- **Runtime `<Trans id="English source">` is the convention on both platforms**, imported
  from `@heliogrid/i18n/react`, never `@lingui/react` (neither app declares it). The
  `@lingui/swc-plugin` fails against this Next version; `packages/i18n/CLAUDE.md` carries
  the exact migration path for when that unblocks.
- **One i18n instance per app mount and per server request — never at module scope.** A
  module-level instance is one mutable active locale shared by every concurrent visitor.
- Language is per USER, not per tenant — and it is NOT the tenant's market. Currency
  grouping, tax scheme and paperwork come from the market pack; a Marathi-reading user in an
  Indian tenant still sees INR in lakh/crore.
- App-facing catalog rules (the Trans convention, untranslated units, script width) live in
  `.claude/rules/cross-platform.md` — they load where screens are authored, which this
  file's paths do not reach.

**Run `pnpm --filter @heliogrid/i18n extract` before committing** — CI fails if the
catalogs are not freshly extracted, and the diff is noisy when it catches you late.
