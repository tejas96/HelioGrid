# Writing rules, not code

- A rule carries no date; when and why something changed is the commit's job. Where a lesson from a
  mistake goes: `CLAUDE.md` §1.
- One fact lives in one file — cite it, never restate it.
- Say the instruction plainly, in words a new reader can act on.
