# SCR-MS-05 · Studio Step 2 — Roof

Touch-first roof CAD over the pinned satellite image with AI detection review; hosts the shared canvas chrome from MS1's contract.

**Module:** MS (Design Studio) · **Personas:** Design Engineer, Sales Executive, Survey Engineer, EPC Owner · **Context of use:** the flagship's core canvas. Design Engineer authors; Sales Executive/Survey Engineer run remote-survey-derived starts (MS2 §2). Web primary; mobile 375 px FULL parity with the S2-1 touch pack — pinch-zoom, two-finger pan, visible snap toggles (F7-30/32). The canvas is light like every other surface — v1 is light-only, with no dark theme and no dark variant of any surface (`foundations/F7`, `F7-04`, P0; the shell carries the same law, SCR-MS-03). Precision touch work, often one-handed on a phone over real satellite imagery.

## Entry & exit

Reached from: Step 2 of the wizard (SCR-MS-03), after Step 1. Wizard-step gate (flagship note): the shell's first gate — **setup completeness** — admits the user to this step; this step's own Next gate is **at least one roof** (MS12-03 order, shell contract; M05-05's example copy "Draw at least one roof"). Leads to: Step 3 — Obstructions (SCR-MS-06) once a roof exists; "View in 3D" opens the 3D scene and returns (MS2-01; the scene is SCR-MS-09). Survey photos ride alongside the canvas as reference (M05-29).

## Data volume

Design at multiple roofs per project: roof chips use an 8-color identity palette by index (MS2-11) and the detection pipeline caps at 8 roofs per import (MS2 doc, PRD context) — so the chip list, stacked mumties (MS2-09, MS2-14) and ghost review with per-shape counts (MS2-39) must all work at roughly eight-plus roofs, each with edge-length chips on every edge (MS2-17) and per-edge setback/parapet overrides (MS2-31/32). Survey photo reference rides alongside the canvas (M05-29).

## Numbers carrying provenance

Each user-visible number carries its F8 provenance tier in the design: **live edge lengths** and typed exact lengths (0.2–500 m equivalent, display unit) (MS2-05, MS2-17); **roof area** on chips, unit-aware (MS2-11, M05-24); **eave height (2–30 m)**, **pitch (0–60°)**, **azimuth/compass readout** (MS2-27, MS2-29); detected **pitch/azimuth suggestions** — suggestion only, never auto-applied (MS2-28); **setback (0–3 m)** and per-edge overrides, **parapet height/width (0.1–3 m / 0.05–1 m)** (MS2-31, MS2-32); **measured vs actual** calibration values, the **×k correction** and **north offset** (MS2-35, M05-26); **ghost confidence** and "N AI-detected entities — dimensions are detector estimates", **imagery quality + date** (M05-23, MS2-39); **live zoom %** and the **scale bar** — computed from the same px/m as hit-testing (MS1-29, MS1-30); the **+2.2 m** mumty stack height and factory defaults (MS2-09). Every dimension is human-entered — never measured from photographs (M05-29).
