# 06 — Offline & Sync — superseded

> **Retired 2026-08-19.** The V2 PRD suite replaced this document. It is kept as a pointer
> because roughly fifty links across the repo still name this path; the content is gone.

**Read instead:** [`prd/registers/open-questions.md`](/prd/registers/open-questions.md)

**This described a capability that no longer exists.** Owner ruling `Q61` (2026-08-07) removed
offline and sync from the product entirely. There is no queue, no sync centre, no staleness
banner and no offline state anywhere in V2. `NoConnection` — a connection-required gate — is the
only sanctioned treatment. Nothing here was carried forward; it is listed only so a link to this
path does not land on a spec that was overruled.
