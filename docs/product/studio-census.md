## 2. TOOL / FEATURE CENSUS (Phase 10, screens 10.1–10.11)

### 10.1 Shell + design list + Design Health
- **Entry/design list:** studio opens from lead "Create design"; a lead holds SEVERAL variants (each shows size, generation, price, payback; one "recommended"); New design / duplicate / open.
- **10-step wizard:** 1 Project setup · 2 Roof · 3 Obstructions · 4 Components · 5 Panel placement (auto — no page of its own) · 6 Manual edit · 7 Proposal · 8 SLD & drawings · 9 BOM & pricing · 10 Final. Step states: not started / in progress / done / has errors. Compact step indicator (mobile "3 / 10 · Roof ‹ ›" → step-list sheet; desktop step rail).
- **Header controls:** back, step title, **Design Health chip**, units toggle (m/ft, global), Save, Save & exit to lead, Help (per-step plain language, folds old keyboard cheats into on-screen help), Next/Done.
- **Per-step Next gate** with plain reason ("Draw at least one roof", "Fix the string design before continuing"); hard electrical gate on layout step.
- **Design Health:** score /100 + band **Good/Fair/Poor** across energy, electrical, roof-utilisation; health sheet shows per-category scores, specific deductions ("−8 · off-south orientation"), and a "what changed since last save" delta; provisional state while shading recalculates.

### 10.2 Step 1 · Project setup & location
- **Pre-fill from survey (Phase 5):** address/location/site details carried over, editable.
- **Fields:** project name; customer name; customer phone; Country (India); State; DISCOM (sets default tariff); Site type Residential/Commercial; Connection Single/Three phase; Sanctioned load (kW); Electricity tariff ₹/kWh (auto-filled, editable); Average monthly bill ₹ (feeds Step-4 size suggestion); Company logo upload (max 5 MB, PNG/JPG); Ground-mount / open-access project (normal option, no PRO/tier gate D38; if not functional mark "coming soon" not "upgrade").
- **Location:** search address (autocomplete) OR enter coordinates; satellite map (redesign pin placement — code has a FIXED pin + drag-map-underneath, confusing on touch; still land on exact roof; keep zoom); "Confirm location" → **Solar Data card** (irradiance kWh/m²/day, peak sun hours, source label → becomes PVGIS-measured once fetched).
- **Site Intelligence (Google Solar Building Insights):** async, four states loading/unavailable/unreachable/ok; ok shows max panels (~kWp), roof area, sunshine h/yr, roof faces, imagery date + quality (HIGH/MED/BASE).
- **Guard:** relocating pin **>25 m WIPES the whole design** (roofs, panels, etc.) — keep guard, make it a clear undoable confirmation not a silent reset.

### 10.3 Step 2 · Roof setup (touch-first CAD)
- **Mode toolbar:** Select · Draw roof · Detect roofs (AI) · Ortho-snap toggle · Show all measurements · Measure distance · View in 3D · Undo · Redo.
- **AI Detect:** geometric pipeline (Google dataLayers → outline, pitch, azimuth, eave height, obstructions, per-shape confidence) then Gemini photo fallback (shapes only, no height/pitch); results as **ghosts** to accept/reject (tap ghost include/exclude, align nudge, "add selected", imagery quality/date, dropped-shape warnings).
- **Roof list:** one chip per roof (select · lock · delete, with area).
- **Drawing (touch):** choose Draw → tap corners; live edge-length labels; CAD snapping (angle-relative, object-snap to other roofs, alignment guide rays, right-angle marks) with visible snap on/off; tap near first point to close; "complete shape?" confirm; undo/last-point-remove; rejects too-close points with a plain message.
- **Editing a roof (tap-select → big handles):** move vertex · insert vertex on edge · delete vertex · move whole roof · rotate whole roof (snap-to-15° control) · tap edge length to type exact metres. Per-roof action set: roof type · height & parapet · exact vertex coordinates (X/Y) · duplicate.
- **Roof type sheet:** RCC flat · Metal shed · Tile · Ground array; where footprint allows Pitched gable (2 faces) or Pitched hip (4 faces) with ridge direction; disabled options explain why.
- **Height & parapet sheet:** height-from-ground; "Google detected N° facing DIR — apply/dismiss" pitch/azimuth suggestion banner; pitch; "slopes toward" picker (tap low edge, compass read-out, "south is best" tip); edge setback (uniform + per-edge); parapet-wall toggle → direction, height, width, auto-skip shared walls, per-side "tap a side to add/remove its wall."
- **Calibration:** measure two points → enter actual metres → applies scale correction (+ expert north offset); rescales all geometry.
- **Dependent-items guard:** geometry change orphaning downstream items → "keep current / keep for review / remove invalid."
- Carries roof provenance (manual / AI-detected + confidence). Add pinch-zoom + two-finger pan (missing in code).

### 10.4 Step 3 · Obstructions
- **Always on screen:** satellite canvas with Step-2 roofs as READ-ONLY backdrop (fill + red-dashed setback inset); every obstruction to scale with a small **ID chip** (type code + number, e.g. WT1, TR2; constant screen size at any zoom); a red-dashed **setback ring** per blocking object; north indicator; graphic scale bar; zoom in/out + live zoom % + fit view; pan/zoom free except while placing/mid-drag; undo/redo (one gesture = one step); units (m/ft).
- **Five tools:** (1) Add obstruction (badge = current count) → type picker; (2) Show/Hide obstructions (also clears selection); (3) Show all measurements (roof + rectangular-obstruction edge labels); (4) Measure distance (two-point ruler, restarts clear prior); (5) Open 3D view (→10.7, returns).
- **Type picker — ELEVEN types** with icon, name, default L×W×H (m): Tank WT 2×1.5×1.2 · Dish DS 1×1×1.2 · Chimney CH 0.8×0.8×2 · Tree TR 3×3×5 · Elevated EL 3×2.5×2.6 · Building BL 8×6×9 · Solar WH SW 2×1.2×1.5 · **Ladder LD 0.6×1.5×3 (BETA marker)** · Windmill WM 1.8×1.8×3.5 · Turbine Vent TV 0.4×0.4×0.5 · Other OB 1.5×1.5×1. Choosing → placement mode ("Click to place {type} · Esc to cancel"); next tap drops at default size; app auto-detects which roof it sits on (or "on ground") and auto-names (WT1, WT2…); cancellable.
- **Selecting an object → (a) direct manipulation:** move (grab point stays under finger, re-checks roof on release), resize rectangle (4 corner handles L/W), resize circle (1 handle diameter), rotate (stem handle, 15° snap or free); **no dimension below 0.3 m**; locked object can't move/resize/rotate.
- **(b) Context action set (exactly seven):** Duplicate (offset copy, recomputes roof) · Shape · Size & rotation · Settings · Lock/Unlock · Delete · Deselect. Precise positioning without a mouse: fine + larger nudge steps, rotate in exact degrees.
- **Shape options:** Rectangle (L×W) or Circle (diameter), switchable.
- **Size & rotation:** typed exactly in current unit; Rectangle L/W/H; Circle diameter/H; Rotation 0–359° in 1° steps. Height drives shadow + bridging maths.
- **Settings (how object affects design):** SETBACK 0–3 m in 0.1 m steps (draws red ring, "buffer zone where panels cannot be placed"); CASTS SHADOW on/off (inclusion in shading sim); **BLOCKS PANEL PLACEMENT on/off → reveals nested bridging chain**: Panels may bridge above on/off → Must remain open to sky on/off → when OFF reveals Clearance above it 0–1 m in 0.05 m steps with a live calc "Bridgeable when the array structure clears X m (its Y m + margin)" + a warning that bridging is flagged for engineer confirmation. CONVERT TO ROOFTOP PLATFORM (one-tap: replaces obstruction with a new roof surface "{label} platform" at roof height + own height so panels mount on top; states structural adequacy needs engineer verification; unavailable when top too small, reason shown). HEIGHT INFORMATION (read-only: placement roof name or "On ground", base surface height, top-from-ground).
- **Live updates:** owning roof (re-checked on move), base/top heights, required bridging clearance, setback ring size, total count.

### 10.5 Step 4 · Components
- **Three parts in order: Panel → Capacity → Inverter** (each shows done-state + current choice, reopenable).
- **Panel:** selected-panel summary (brand, model, dimensions, Voc/Vmp/Isc, wattage large); Search; **Filters** (min/max watt; Technology: All Types · Mono PERC · TOPCon · Bifacial · Poly · HJT; DCR on/off; ALMM on/off); result count; list rows (brand mark, brand+model, "watt · technology · dimensions", ALMM/DCR badges); two "available-later" routes: enter specs manually + upload datasheet (PDF extraction).
- **Capacity:** target capacity kWp (0.1 steps); **Auto** = maximum fit after setbacks + obstructions (unavailable until panel chosen + roof exists); Google Solar cross-check line ("estimates max N panels ~X kWp", info only); **bill-based suggestion** ("From your ₹X/month bill we recommend ~Y kWp", tap applies, X from Step 1); Continue unavailable while capacity 0.
- **Inverter:** recommended line ("Recommended: {brand} {model} ({kW}×{count}, {phase}) → DC/AC ratio X", tap applies); selected summary (brand, model, #MPPTs, voltage range, phases, efficiency, kW large); number of inverters 1–10; **DC/AC ratio live health: >1.35 high (clipping risk), <0.90 low (oversized), 0.90–1.35 healthy**; search + count + list (kW · phase · MPPT count · voltage range, recommended badge). After inverter chosen: **DC collection topology** (String inverters / Central + combiners), **MLPE** (None / DC optimisers).
- **Compare options** (unavailable with no roof): states BASIS (target vs max fill, PVGIS vs built-in estimate, catalog version, warnings); per-candidate comparison: Option (panel, RECOMMENDED/CURRENT markers, on-order/DCR note) · Inverter (+DC/AC ratio) · Fits (panels×watt→kWp) · Module efficiency · Annual generation kWh · Net cost (subsidy shown separately) · Payback · 25-year savings (+ROI%) · Warranty (panel/inverter yrs) · Install (complexity + array weight) · Apply/selected/feasibility; decision cards (topic, choice, reason, inputs); fixed-assumptions footnote (tariff escalation/yr, 25-yr horizon, margin, PM Surya Ghar subsidy); Apply sets panel+inverter+count in one undoable action; if panels already placed with a different panel → replace-panel confirmation.
- **Live updates:** module efficiency, annual kWh, net cost, subsidy, payback, 25-yr savings, ROI%, DC/AC ratio, array weight, install complexity, valid-string existence, recommended inverter+count, effective kWp roofs hold, bill-based suggestion.

### 10.6 Steps 5–6 · Panel layout (most tool-dense screen)
- **Arrival (0 panels, "Step 5"):** Place manually / Auto-fill panels (to Step-4 target) / Use maximum roof capacity.
- **VIEW tools:** Irradiance heatmap (legend Poor→Excellent 0/50/100% + Jan–Dec month scrubber recolouring instantly + current-month avg access %, avg sun-hrs/day, kWh/m²; progress "Computing solar access… X%"); Show strings (series path + routed home-runs); **Why this layout?** (Design Decision Log + accept/ignore improvement suggestions); Measure distance.
- **BUILD tools:** Select (default: select/multi-select/move panels/edit cable corners); Panels (TAP = one panel snapped to grid; DRAG = fills a rectangle with a table, auto-avoiding obstructions + setbacks; live fit/conflict preview); Erase (removes panel/walkway/rail/arrester/inverter/meter under pointer, highlights target first).
- **SAFETY (each w/ count):** Walkway (drag lane; width 600/800/1000 mm or custom 100–3000 mm); No-build zone/keep-out (drag rectangle; tap existing to remove); Safety rail (drag along edge); Lightning arrester (tap to place).
- **ELECTRICAL (each w/ count):** Mount inverter (two sub-modes via toggle: Inverter snaps to nearest wall edge within ~4 m; Meter/service entry as free point; each shows its own instruction); Stringing (→ section 5); String connections (read-only list of every string + exact panel chain).
- **Always available:** Undo/Redo (one gesture=one step); Lock/Unlock layout; Clear all panels (confirm first, unavailable when locked or empty).
- **Canvas:** pan/zoom (Select mode, suspended mid-gesture); tap select; marquee box select + add-to-selection; move (live outline, refused move explains why); cable-route editing (drag corner points, pull straight segment for new corner, marks run MANUAL so auto-routing won't overwrite, both ends fixed); every draw tool previews live.
- **When panels selected:** shows count, then Group (loose→parametric TABLE, needs 2+ same roof not grouped); Grow a row/column (one tap on side with space, says when no room); More grow options (axis row/col, count 1–20, side, live preview, "Add N"); Rotate (90° each way, azimuth shown or "mixed"); Tilt (5° steps, current shown); Table settings (only when table selected); Enable/Disable (stops production without deleting); Delete; Clear selection. All disabled when locked.
- **Stringing options:** Auto string (groups into valid strings for inverter MPPTs + auto-routes DC/AC); Manual string (tap-to-wire; live "N of min–max panels" counter, running cold-weather string VOLTAGE coloured over-limit/under-MPPT-floor/fine, too-long/too-short warnings, Save/Cancel, refuses used/disabled panels with reason); Clear strings (only when strings exist).
- **Table settings (parametric array + structure):** header (name, rows×cols, panel count, kWp); Structure preset (Flush · Standard 10° · Walk-under 2.2 m, cross-section previews, "custom" when none match); Ground foundation, ground-mount only (Driven pile · Ballasted, "soil survey required"); Racking (Flush · Fixed tilt · Dual tilt); Panel tilt (when not flush, 0–35°); Inter-row shading (when not flush: recommended winter shadow-free row pitch m, resulting GCR, one-tap "Apply shadow-free spacing"); Azimuth (±5° steps, Due South preset, Roof slope preset, live degrees + compass); Structure profile (steel section, weight per metre); **Structure member model** (preview + counted bill: legs, rafters, purlins, braces — count + total metres — and total steel kg; editable leg spacing 0.5–4 m + clearance 0–3 m + Anchored/Ballasted; structural warnings); **Structure disclaimer always** (material estimate + visual model, not a wind/uplift/roof-capacity check, needs engineer verification); Duplicate table; Delete table.
- **Validation & status:** validation summary (first problem + "+N more") → full list of errors/warnings: string voltage too high in cold, voltage below MPPT window, panel current above MPPT input, DC/AC too high/low, panels unstrung, more strings than MPPT inputs, "no valid string length exists for this panel/inverter pair"; every entry taps to LOCATE (centres + selects faulty panels); inline "Auto-string now" where relevant. **Hard gate:** invalid electrical blocks next step, reason stated. Status read-out: enabled panel count, kWp vs target, string colour key, DC cable length (routed vs estimate). 3D button. **No subscription/plan-capacity limit anywhere (D38); flagging kWp over TARGET stays as a design cue.**

### 10.7 The 3D view (one shared surface, opened over editor steps)
- **Camera:** orbit/pan/zoom (never below horizon); three presets Top/Isometric/Front; close→2D; on-screen equivalents for all keyboard-only controls.
- **Sun & shadow:** season presets Winter/Summer/Equinox/Today; date picker; Play/Pause (animates sun, shadows move); time-of-day 5 AM–7 PM; sunrise/sunset; sun-position read-out (compass + azimuth/altitude °); sun-path toggle (arc w/ hours). Shadows cast by roofs, parapets, obstructions, structure, panels.
- **Layers/view modes:** Irradiance heatmap (moves to top-down, stops rotation, legend Poor→Excellent + month track w/ avg access %, sun-hrs/day, kWh/m² — kWh/m² carries "Real · PVGIS" marker, geometric access numbers deliberately carry NO marker; progress while computing); Solar-access view (tints each panel by actual sun); Energy report (→section 6); **Map ⇄ Mesh** (Map = model on satellite in context; Mesh = isolated product render on plain background); **Neighbour buildings** (decorative only — state plainly they do NOT cast shadows; a real neighbour must be added as a "building" obstruction in Step 3); Copy customer share link (read-only 3D, hidden in read-only mode); Back to 2D.
- **Editing in 3D** (tap module or structure member → edit card): This panel (solar-access %, share of annual kWh, "SUN LOST TO — tap to look" list, tap blocker swings camera; says so if nothing blocks); Structure presets Flush/Standard 10°/Walk-under 2.2 m; Module visibility Show/Ghost/Hide (view aid, never saved); Table scope All tables/Isolate this one (view aid); Structure profile (steel section, cross-section shape, size mm, weight/m); **Foundation** (PCC pedestal · Chemical anchor · Ballast block · Driven pile; options taller than clearance unavailable w/ reason; only where surface allows); Shuttering form (cast pedestals only: Square or Circular, circular ≈ ⅕ less concrete); **Foundation honesty note** (size nominal + assumed, adds roof weight, roof capacity NOT checked); Tilt (5° steps, 0–35°); Clearance (0.3 m steps, 0–3 m); Customise mounting structure (Purlins per row 1–6 · Rafter density 1–3× half steps · End overhang 0–1 m · Bracing on/off; note rafter density is a material allowance not a safety factor); Edit legs (2D) (top-down plan, Auto/Custom marker + leg count, Add leg, Reset to auto, each leg draggable/nudgeable/removable, legs may not leave buildable area, actions announced).
- **Energy report** (in order): freshness note when shading recalculating (provisional); system summary (kWp, panel count + per-panel W, roof area); annual generation (annual MWh large + specific yield kWh/kWp + performance ratio % + POA factor, provenance line "Real irradiance — PVGIS ({database}, {N}-year record)" OR "Built-in irradiance model (latitude fit, ±10%)"); monthly generation (12 months, monsoon distinct, exact kWh); **losses breakdown** (temperature, soiling, inverter, mismatch, DC wiring, measured shading, + total, each with %); solar access (avg %, same metric as heatmap); 25-year projection (lifetime MWh + year-25 output w/ % of year 1); financials (net cost after subsidy, yearly savings at tariff, payback yrs); financing options (card per option, headline + monthly, "representative terms"); actions Customize Proposal (→Step 7) + Quick Generate (→proposal), hidden in read-only. Charts use DATA colours never brass accent.
- **Read-only (customer share) state:** no edit controls, no share button.

Controls: Capture (from current 3D view); progress "Shadow captures: N of 4"; four numbered shot buttons (tick when captured, tap to jump/retake); auto-advances to next uncaptured; **first capture auto-becomes cover image**; Skip to review; save-error state (storage full / private browsing, honest + remedy).
- **Phase B — Review:** "Before you issue" readiness card — verdict NOT READY · READY WITH CAVEATS · READY TO ISSUE; each checked thing w/ status (ready/needs attention/blocking) + meaning + jump button to the fixing step; cover image preview (or "no cover captured yet"); the shadow set (four captures; each shows image or "Not captured", name, date/hour, "OUTDATED — RETAKE" when design changed since, "COVER IMAGE" marker or "SET AS COVER"); system summary (kWp, panel count × watts, avg solar access %, annual generation); Edit photos (→capture studio); Generate proposal (marks design proposal-ready, hands numbers + captures to Phase 3 Path A). **A capture taken before a design change is stale and must say so, not silently show an out-of-date picture.**

### 10.9 Step 8 · SLD & drawings
- **Four drawing tabs:** SLD · PV Layout · String Route · Structure. Each a proper drawing sheet (zoom/pan within its area) + title block (project, client, date, sheet name) + "not to scale" note.
  - **SLD:** each string w/ panel count + voltage; string combiner boxes (central topology); DCDB w/ fuse, SPD, isolator; inverter (label, kW, phase, MPPT range, unit count); ACDB w/ MCCB, SPD, isolator; generation + net meters + grid; earthing pits; String/MPPT schedule table; Plant details table; structural disclaimer note.
  - **PV Layout:** roofs w/ edge dimensions, every panel, obstruction buffers, north arrow, legend, array-table detail, title block.
  - **String Route:** roof outlines + each string's cable route labelled + string schedule (says so when nothing strung).
  - **Structure:** structural drawing of the mounting system.
- **Compliance check (SLD):** **MAXIMUM SYSTEM VOLTAGE box** — longest string's cold-weather voltage vs inverter max DC voltage; within = passing, over = fault + "shorten the string"; must be prominent (the figure an electrical inspector checks).
- **Controls:** Three-line toggle (SLD only — draw line/neutral/earth vs single-line shorthand); **Edit ratings** (SLD only, count of overrides) form: Inverter name/model + AC rating kW; DC side cable mm² (2.5/4/6/10) · fuse A (15/20/25/32) · SPD type (Type-I / Type-II / Type-I+II) · isolator A (25/32/40/63); AC side cable mm² (4 up to 95) · cable type (PVC copper / XLPE copper / XLPE aluminium) · MCCB rating A (also sets isolator) · SPD type; Grid & standards (IS/IEC 62548·CEA, IEC 60364-7-712, or NEC 690); Reset to auto (disabled when nothing overridden), Cancel, Save (only values differing from derived defaults kept); **Structural verification** two-state Pending verification ⇄ Engineer approved (human sign-off, app never computes structural adequacy); **High-wind marker** derived from site state (display only, engineer verification mandatory in high-wind zone); Exports SVG (CAD) · PNG · DXF (layout) · Print/Save as PDF; empty state when nothing strung (Auto-string now — unavailable until panel + inverter + ≥1 placed panel, w/ reason — and String manually in editor); first-visit colour-legend explainer (DC/inverter/AC/earthing, dismissable).

### 10.10 Step 9 · BOM & pricing (the ~286-control screen)
- **Money summary — nine figures, two editable:** System kWp · Cost before margin · **Margin % (editable 0–60)** · **Discount (editable, value + % or ₹)** · Taxable (with "−₹X off" line when discounted) · GST (per-rate breakdown when mixed rates) · Quote total · ₹ per Wp · Subsidy (+ reason when ₹0). Same arithmetic the proposal uses — cannot produce a different total.
- **Six categories (in order, shown only if they have lines):** Modules · Inverter · Electrical BOS · Mechanical BOS · Safety · Civil & Misc. Each: name, "N of M included", own total, Refresh-from-design action (appears once anything hand-edited). Electrical BOS also holds two survey inputs sizing the cable: Average DC run (array→inverter) + Average AC run (inverter→LT panel); locked with a note when the design has real routed cable geometry (routed length used instead).
- **Every line item (no field dropped):** Include switch (excluding keeps but drops from totals + dims, never deleted); **Confidence indicator MEASURED · DERIVED · ESTIMATED · ASSUMED** (counted from design / computed from geometry / labelled fallback / needs surveyor-engineer confirm — readable not decorative); Item name (editable on custom, fixed on derived); Spec · Brand (text); Quantity (number); Unit (nos · set · pairs · kit · lot · plate · panel-set · day · m · m² · kg · kW); Waste % (0–100); Order quantity (calc = quantity + waste, rounded up for whole-unit items, read-only); Rate ₹; Amount ₹ (calc, read-only); GST % (0–40); GST ₹ + Total ₹ (calc, read-only); Derivation explanation (opens the formula in words); Remove (custom lines only); per-field reset (appears next to overridden values, changes appearance when design has moved on).
- **Reconciliation:** stale notice per category ("yours X · design now Y" per drifted field + one-tap "Take Y" + bulk "Refresh these" + "and N more"); orphan notice (saved edit whose line no longer exists → Keep as custom line / Discard); below-cost warning (discount sells under cost); preliminary-quote notice (how many lines assumed/estimated, which figures need site verification); structure engineering disclaimer w/ site's wind zone (material estimate not a safety check).
- **Page-level actions:** Add a custom line; Re-sync all (discards every hand-edit, confirm first + states edits lost, disabled when nothing edited); Export CSV; **DISCOM compliance checklist** (net metering vs sanctioned load · SLD sign-off · module ALMM/BIS listed · earthing + lightning-arrester certificates · PM Surya Ghar subsidy eligibility incl. DCR caveat). Totals ARE the proposal money path; each line's confidence + preliminary state travel onto the proposal's honesty labelling.

### 10.11 Step 10 · Done + engineer sign-off
- **Done screen:** states design complete, shows design/project name, reassures reopen/edit anytime. Five actions: View proposal · BOM & pricing (→Step 9) · Installation plan (existing InstallationSheet) · Copy 3D share link · Done (→lead's design list).
- **Installation plan (REUSE, don't rebuild):** crew work-order derived from design, ordered how it's built, grouped into phases; progress indicator + "done of total steps"; each step a tick-off item (number, title, detail, materials needed; tap toggles done, remembered); phase headings; Print; empty state ("place modules and string the array first"). **Crew sees NO money — work order, not a quote.**
- **Engineer sign-off queue:** for Engineer role; designs waiting **OLDEST FIRST**; each entry: customer, system size, who designed it, how long waiting; open → review.
- **Review — approve or return:** engineer sees design + drawings, chooses: **Approve** (records structural verification = Engineer approved; design can now go to customer) OR **Return with comments** (each comment PINNED to the thing it refers to, not a loose note; design goes back to designer + notification). **Rule that does not bend: the app NEVER computes structural adequacy — human decision, recorded with who + when; an unapproved design is never shown to the customer.**
- **Design list for a lead:** several variants compared (system size, annual generation, price, payback), one marked RECOMMENDED, open/duplicate/new variant.
