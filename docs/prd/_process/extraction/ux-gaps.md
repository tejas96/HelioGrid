**Frame carried from the register head (applies to every row below, do not restate per-row):**
- The **80** mockups vendored at `design/mockups/` are production specs for most of the product ("Count verified against disk 2026-07-30: exactly 80 `*.dc.html` … Earlier '85' references were wrong under any counting"). This register lists every screen or flow the mockups do **not** cover.
- Each gap is **"designed at implementation time"** — by the implementing agent/designer, directly in the design system, inside the module's build slice. **"No new Claude-Design phase."**
- A gap is closed when the screen ships **wired into its flow (never orphaned)**, with **loading/empty/error/offline states, both breakpoints, and the light theme correct** (light-only per docs/15 R19-A).
- Register rules: check the table before building a module and claim your slice's gaps; closing = ship + mark `CLOSED (PR/date)`, **never delete rows**; new gaps are appended in the same format; "Blocks" names the roadmap item that cannot reach done while the gap is open.
- **Everything-in directive (2026-07-24):** every phase label lands inside the single build (docs/14 tracks) — "Launch-1 …" rows → Tracks A/B/C, "Launch-2 …" rows → Tracks C/M, "studio port" rows → Track D, offline rows → Track E. **UXG-11 and UXG-05 are IN-SCOPE — no v1.1 exists.** Only spec-locked exclusions (D29 crew login, D32 WhatsApp sending) stay out, **"by product law not by timeline."** `OVERLAY:` the 20-day calendar it referenced is retired (docs/15 §4 directive 5 — "the track dependency structure, not the calendar"; scope commitment stands, day numbers do not). Phase labels are kept verbatim in the notes column as source pointers, not as schedule.
- Cross-cutting: notification types for the new v1 systems (billing events, sync failures, number-provisioning status) **extend the existing NotificationsCentre patterns; register them in each module's slice rather than as separate screens** → F6. Every gap inherits the mockups' cross-cutting contracts: **dual breakpoints, teaching empty states, provenance labels, sheets-not-pages, arc-nav/sidebar shells**.
