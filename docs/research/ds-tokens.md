## 6. OTHER RENDERING-AFFECTING PACKAGE FACTS

- **Custom-property naming scheme:** flat kebab-case with role prefixes — `--sp-*` (spacing steps, `-0-5` for fractional 2px), `--r-*` (expressive radius) / `--rf-*` (functional radius), `--e0–e5` (elevation), `--dur-*` / `--ease-*` (motion), `--fs-*` (font-size) / `--lh-*` (line-height) / `--tr-*` (tracking) / `--fw-*` (weight), `--chart-1..8`, plus a semantic-alias layer (`--bg-page`, `--surface-card`, `--text-body`, `--link`, `--focus-ring`) pointing at raw tokens.
- **Density mode is data-attribute-driven:** `:root[data-mode="expressive"]` is the only selector variant present (typography.css). Density otherwise flips via paired token families (`--sp-*` expressive vs `--screen-pad-*-fn`; `--r-*` vs `--rf-*`; `--r-card-expressive` 24px vs `--r-card-functional` 12px; `--r-input-expressive` 14px vs `--r-input-functional` 10px). Readme: same colours/type/rules — only spacing + radius change; default Expressive on mobile, Functional on desktop data screens.
- **Per-`@kind` annotations:** many tokens carry trailing `/* @kind font|spacing|radius|shadow|other */` comments (tooling metadata for the adherence linter `_adherence.oxlintrc.json` / bundle); they do not affect CSS.
- **Component/bundle:** compiled runtime is `_ds_bundle.js`, exposed as `window.HelioGridDesignSystem_c8aa43`; component cards/UI kits render blank until it compiles. No component CSS lives in `tokens/`.
- **Font caveat:** readme claims "variable woff2 + static fallbacks" but `assets/fonts/` contains **only** the two variable woff2 files — no static fallbacks are shipped.
- **Iconography (not tokenised, affects render):** Lucide, outlined, 1.5px stroke, round caps/joins; 24px default / 20px functional / 28px bottom-nav; circular icon container 40px expressive / 32px functional at 6% colour tint.
